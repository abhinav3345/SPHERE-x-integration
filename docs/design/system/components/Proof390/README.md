# Proof390

A proof that the components hold together in one 390px column. It is not the site design.

Order, top to bottom: app bar (wordmark, Live data chip, Copy link), search, moved-object banner, image frame edge to edge with its margin and readout, frame label, playback with the flip key first, timeline, view switch, band selector, field of view, display controls, provenance.

What it proves:

- One lit control in view at a time: the banner's action here.
- The image frame, readout and frame label have fixed sizes, so stepping frames moves nothing.
- Every pressable thing is at least 44px high, and the flip key lands in the lower third of a phone screen.
- 16px gutters everywhere except the image, which runs edge to edge.
- Colour appears only on the markers.
