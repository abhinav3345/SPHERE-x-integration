# Proof1280

A proof that the same components fit one 1280 × 720 screen with no scrolling. It is not the site design.

Layout: app bar with the search field in line; then three columns. The image column is 476px (the 119px frame at 4×) with the scale bar, compass, readout and frame label under it. Two rails of about 362px hold the banner, playback and timeline, then view, band, field of view, display and provenance.

What it proves:

- Everything needed to drive a demonstration is on screen at once, at projector resolution.
- Primary text is `color-text` on `color-bg` (16.9:1) and secondary text is 9.3:1, so nothing depends on faint grey.
- The image has neutral surround on every side and no lit control touches it.
- The rails use the phone components unchanged; only the search field switches to its inline form.
