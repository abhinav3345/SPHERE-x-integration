Copy list

Every string the comparator can put on screen, in the order of the screen. Numbers are today's measurements: "Changes" says what the results file fills in and how wide the field must stay so that nothing moves.

A dot (·) between strings separates strings that sit in one control. Square brackets mark a slot whose value is not in the brief or in the system.

The column "From"

System
Word for word from the Tombaugh system's cards.
Brief
Word for word from the brief, or a fact the brief gives.
Viewer
Read off today's viewer.
New
Written for this design in the system's voice, or not found word for word in the cards. Check these first.

No string here has an exclamation mark. The screen claims no detection, so neither "candidate" nor "discovery" appears on it.
